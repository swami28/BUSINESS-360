# Power Query sources

Create a **Text** parameter called `ProjectRoot` containing the absolute project directory on the machine running Power BI Desktop (no trailing slash or backslash). Create five blank queries named `FactSales`, `DimDate`, `DimDepartment`, `DimProduct`, and `DimRegion`; paste the matching `.m` file into each Advanced Editor. Each query chooses the appropriate path separator for Windows or Unix. Run `python scripts/build_demo.py` first. Refresh after rebuilding the SQLite extracts.

The fact and date CSVs are extracts from the SQLite database; the three other dimensions come directly from CSV files. This is an import workflow, not a live database connection. If a SQLite ODBC driver is installed, `fact-sales-odbc.example.m` illustrates replacing the FactSales extract with a direct SQLite SQL query. Configure a **64-bit** ODBC DSN named `Business360SQLite` pointing to the generated database; then replace the FactSales query contents with that example. The DSN and driver must also be configured on any refresh host/gateway. ODBC driver behavior varies; verify types and test refresh in your environment. DimDate can remain an extract or be connected similarly. Rebuilding the database requires a subsequent Power BI refresh.
